# Release Notes - LLMFlow v0.3.2

Release Date: 2025-12-21

Patch release fixing issues around Anthropic passthrough mode and streaming token tracking.

## Bug Fixes

### Anthropic Passthrough Mode (Critical)

Issue: The `/passthrough/anthropic/*` endpoint returned `{"error":"Invalid JSON response","body":""}` instead of the actual Anthropic API response.

Root cause: The passthrough handler attempted to parse the response as JSON and, on failure, returned an error wrapper instead of the raw upstream response.

Fix: Passthrough now forwards raw bytes to the client via `res.write(chunk)` and buffers separately for logging. JSON parsing failures no longer affect the client response.

Impact: Claude Code, Aider (Anthropic mode), and native Anthropic SDK users can now use LLMFlow passthrough.

### Streaming Token Counts (Medium)

Issue: Dashboard showed 0 tokens for streaming requests.

Root cause: SSE events were parsed per TCP chunk, but JSON payloads often span multiple chunks. `parseStreamChunk()` failed on incomplete JSON, leaving token usage as null.

Fix: Proxy and passthrough streaming handlers now buffer the complete SSE stream and parse it once at the end.

### Dashboard API Filtering by Provider (Low)

Issue: Query parameter `?provider=anthropic` was ignored — `/api/traces` returned all traces.

Root cause: The API endpoint wasn't extracting the `provider` query param, and `db.getTraces()` had no SQL WHERE clause for provider filtering.

Fix:

- Added `provider` and `tag` filter support to `db.getTraces()`
- Added query param extraction in `/api/traces` and `/api/traces/export`

## Clarification

### Proxy Mode Format Conversion (Not a Bug)

The `/anthropic/v1/*` proxy routes convert Anthropic responses to OpenAI-compatible format by design, for consistency across providers.

For native Anthropic format, use `/passthrough/anthropic/v1/messages`.

## Upgrade Guide

```bash
# Using npx (always gets latest)
npx llmflow@latest

# Using Docker
docker pull helgesverre/llmflow:v0.3.2
docker pull helgesverre/llmflow:latest

# From source
git pull origin main
npm install
npm start
```
