**Application findings — nine additional bugs**

1. **HIGH — Analytics crashes when cost-by-tool data exists.** The DB returns `provider` and `service_name`; the API forwards them without a `tool` field. The UI calls `tool.tool.toLowerCase()`. Opening Analytics with seeded cost records reproduced `Cannot read properties of undefined (reading 'toLowerCase')` in Chromium and left panels empty. Define the intended grouping/display label explicitly at the API boundary and assert a real row renders without page errors. Sources: [DB grouping](/Users/helge/code/llmflow/packages/db/src/index.ts:1175), [API mapping](/Users/helge/code/llmflow/apps/server/src/server.ts:195), [UI dereference](/Users/helge/code/llmflow/apps/dashboard/src/lib/components/analytics/AnalyticsTab.svelte:120).

2. **HIGH — Daily analytics uses incompatible field names.** The API sends `tokens`, `cost` and `requests`; the UI reads `total_tokens`, `total_cost` and `request_count`. Its prompt-token series also reads `prompt_tokens`, which the daily response does not contain. Nonempty API buckets therefore calculate invalid bar heights and cannot populate the intended totals. The local response contained nonzero daily values, while Chromium showed zero-height bars; the separate cost-by-tool crash also blocks complete rendering. Map the daily response consistently and either provide the prompt aggregate or remove that unsupported series. Sources: [DB daily result](/Users/helge/code/llmflow/packages/db/src/index.ts:1232), [API response](/Users/helge/code/llmflow/apps/server/src/server.ts:759), [UI contract](/Users/helge/code/llmflow/apps/dashboard/src/lib/stores/analytics.svelte.ts:3), [chart](/Users/helge/code/llmflow/apps/dashboard/src/lib/components/analytics/AnalyticsTab.svelte:77), [table](/Users/helge/code/llmflow/apps/dashboard/src/lib/components/analytics/AnalyticsTab.svelte:192).

3. **HIGH — Clicking a session trace opens Timeline instead of the trace.** The click handler writes `#traces?trace=<id>`, but the hash parser accepts only an exact tab name. Nothing consumes the trace parameter or selects the trace. Chromium reproduced the URL containing the requested span ID while Timeline was active. Use canonical `#traces` and explicitly select the root span, or implement the URL contract consistently. Sources: [click handler](/Users/helge/code/llmflow/apps/dashboard/src/lib/components/sessions/SessionsTab.svelte:16), [hash parser](/Users/helge/code/llmflow/apps/dashboard/src/lib/stores/tabs.svelte.ts:12).

4. **MEDIUM — Metrics does not update when live records arrive.** The server broadcasts `new_metric`, but the dashboard metrics store never subscribes. Chromium received one `new_metric` event while its table remained at eight rows; pressing `r` revealed the ninth. Subscribe to the event and refresh the filtered list and summary, using the existing subscription pattern. Sources: [broadcast](/Users/helge/code/llmflow/apps/server/src/server.ts:95), [metrics store](/Users/helge/code/llmflow/apps/dashboard/src/lib/stores/metrics.svelte.ts:1).

5. **MEDIUM — Sessions after the first 50 are inaccessible.** The API supports limit/offset and returns total; the store preserves total but the view has no pagination or load-more action. Local reproduction: API total 52, response/UI rows 50, no session paging buttons. Add a small paging/load-more control backed by the existing API. Sources: [API](/Users/helge/code/llmflow/apps/server/src/server.ts:542), [store](/Users/helge/code/llmflow/apps/dashboard/src/lib/stores/sessions.svelte.ts:29), [list](/Users/helge/code/llmflow/apps/dashboard/src/lib/components/sessions/SessionList.svelte:33).

6. **MEDIUM — Timeline's fixed “Tools” choices filter an arbitrary service-name field.** The five hardcoded values are sent to an exact `service_name` filter. A normal OTLP service such as `my-agent` is impossible to select, and every offered choice can return nothing. Populate real service names or offer a text service filter; name the control for the field it actually filters. Sources: [dropdown](/Users/helge/code/llmflow/apps/dashboard/src/lib/components/timeline/TimelineTab.svelte:66), [API filter](/Users/helge/code/llmflow/apps/server/src/server.ts:579).

7. **MEDIUM — Direct span ingestion drops correlation metadata supported by the DB.** `/api/spans` omits `session_id`, `conversation_id` and `agent_name` from its insert whitelist, while the DB and OTLP ingestion support them. A successful direct POST containing a session ID was absent from `/api/sessions`; equivalent OTLP ingestion populated the session. Pass through the supported optional fields and assert the endpoint round trip. This is an API/DB inconsistency, not a claim that the SDK already documents those options. Sources: [direct route](/Users/helge/code/llmflow/apps/server/src/server.ts:803), [schema](/Users/helge/code/llmflow/packages/db/src/index.ts:180), [OTLP fields](/Users/helge/code/llmflow/packages/otlp/src/traces.js:424).

8. **MEDIUM — OTLP unknown duration becomes a real zero.** Missing, malformed or reversed timestamps produce `duration_ms: 0`, destroying the DB/UI distinction between unknown and instantaneous. A real `/v1/traces` request with a missing end timestamp returned a tree with duration 0 and end_time equal to start_time. Store null for unknown/invalid timestamp pairs; preserve zero for valid equal timestamps. Sources: [transform](/Users/helge/code/llmflow/packages/otlp/src/traces.js:350), [nullable trace type](/Users/helge/code/llmflow/packages/db/src/index.ts:361).

9. **LOW — Header still shows valid zero totals as missing.** The header uses `> 0` checks, so a real zero-token, zero-cost or zero-latency trace displays dashes for those aggregates. Use the existing null-aware formatters instead of positive-value tests. Source: [Header](/Users/helge/code/llmflow/apps/dashboard/src/lib/components/layout/Header.svelte:72). Verified by source inspection; not separately browser-reproduced in this pass.
